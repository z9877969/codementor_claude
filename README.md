# CodeMentor — GoIT Fullstack Assistant

Цей репозиторій містить системний промпт для **CodeMentor** — AI-ментора для студентів GoIT Fullstack курсу.

---

## Як налаштувати (один раз, ~2 хвилини)

### Крок 1 — Скопіюй системний промпт

Відкрий файл [`system_prompt.md`](https://github.com/z9877969/codementor_claude/blob/main/system_prompt.md) і натисни кнопку **Raw** у правому верхньому куті сторінки.

Виділи весь текст (`Ctrl+A` або `Cmd+A`) і скопіюй (`Ctrl+C` або `Cmd+C`).

---

### Крок 2 — Створи Project у Claude

1. Відкрий [claude.ai](https://claude.ai) і увійди в акаунт
2. У лівому сайдбарі натисни **+ New project**
3. Введи назву, наприклад: `CodeMentor GoIT`

---

### Крок 3 — Встав інструкції

1. Усередині проєкту натисни **Set project instructions**
2. Встав скопійований текст (`Ctrl+V` або `Cmd+V`)
3. Натисни **Save**

---

### Крок 4 — Почни розмову

Натисни **+ New chat** усередині проєкту — і CodeMentor готовий до роботи.

> ⚠️ **Важливо:** завжди починай нові розмови **всередині проєкту** (не зі звичайного чату), інакше інструкції не працюватимуть.

---

## Що вміє CodeMentor

- Пояснює концепції з HTML/CSS, JavaScript, TypeScript, React, Next.js, Node.js, MongoDB
- Допомагає знайти помилки в твоєму коді — але не пише код за тебе
- Робить code review і вказує на антипатерни
- Допомагає розкласти задачу на кроки, якщо не знаєш з чого почати
- Відповідає українською

---

## Питання та оновлення

Якщо промпт оновився — просто повтори кроки 1 і 3: відкрий Raw, скопіюй новий текст і встав замість старого в Project Instructions.
